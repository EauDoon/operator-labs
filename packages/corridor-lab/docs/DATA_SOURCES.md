# Data sources

Version 0.2.0 ships with no external datasets and makes no network requests.
All bundled values are fictional.

The following official sources are bounded conceptual references for the terms
used in the model. They are not bundled as data, imported into calculations, or
reproduced as a methodology:

- [World Bank Remittance Prices Worldwide methodology](https://remittanceprices.worldbank.org/methodology)
  for the distinct concepts of fees, exchange-rate margin, and speed.
- [BIS Project Nexus payment scope](https://docs.bis.org/nexus/payment-setup/scope-of-nexus-payments)
  for high-level payment-flow vocabulary.
- [BIS Project Nexus FX-provider role](https://docs.bis.org/nexus/fx-provision/role-of-the-fx-provider)
  for high-level FX-provider vocabulary.
- [CPMI ISO 20022 harmonisation requirements](https://www.bis.org/cpmi/publ/d230.htm)
  for context on common payment-message requirements.

Corridor Lab does not claim to reproduce any external methodology, payment
arrangement, source dataset, or published result. Users who adapt the model are
responsible for documenting their own source, permission, and update process
outside this repository.
